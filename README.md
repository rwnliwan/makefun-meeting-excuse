> I have a doctor's note excusing me from this meeting. It was signed by this meeting.

One line, 84 characters. The excuse is a doctor's note — the office's most
recognisable permission slip — and the signature on it is the meeting itself.

## How it runs

`main.ts` (Node, standard library only) writes the entry text to
`/output/entry.txt` (or `$ENTRY_OUTPUT` when set). The gate requires UTF-8
text of 1–200 characters; this entry is 84.
